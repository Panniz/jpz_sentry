# jpz_sentry Module

## Overview
The `jpz_sentry` module is a PrestaShop module designed to integrate Sentry for error tracking and monitoring. This module provides a configuration page where users can input their SENTRY_CODE.

## Installation
1. Download the `jpz_sentry` module.
2. Upload the module to your PrestaShop installation via the Modules section.
3. Install the module from the Modules page in the PrestaShop back office.

## Configuration
After installation, navigate to the module's configuration page to enter your SENTRY_CODE. This code is essential for connecting your PrestaShop store to Sentry.

## Usage
Once configured, the module will automatically send error reports to Sentry, allowing you to monitor and manage errors effectively.
